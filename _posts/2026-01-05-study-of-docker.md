오늘은 도커에 대해 공부했다.

도커란 어느 시스템에서도 돌아갈 수 있는 파일 뭉치를 만드는 프로그램이다.


이전에 캐글에서 진행했던 스트림릿 대시보드를 사용하면서, 죽으면 수동으로 다시 켰어야 하는데, 도커를 이용하면 이에 대한 문제가 해결된다.

또한, 스트림릿이 내 컴퓨터에 최적화되어 있었는데 도커를 사용하면서 다른 컴퓨터에서도 작동할 수 있게 만들었다.
(물론 인터넷 설정은 별개겠지만 이는 제쳐두고 생각한다.)

그래서 도커를 이용해서 내 스트림릿 대시보드를 이미지로 만들어 컨테이너로도 만들었다.

다만 parquet파일을 포함하면 약 1.5기가의 도커 이미지가 생성되는데, 이미지에 포함시키지 않고 파케이를 별도로 사용할 수 있던 점도 좋았다.

그 후에 도커 허브에도 올려보았는데, 아직 윈도우나 맥에서 돌려보진 않았지만 잘 작동되는 것 같다.

아직 도커에 대한 개념이 제대로 정립이 안되서 좀 헷갈렸지만 재밌었다.



그래서 정립해본 개념은 이렇다.

도커는 컨테이너를 관리하는 프로그램이다.

도커는 컨테이너를 실행하고 관리할 수 있다.

컨테이너는 이미지가 있어야 실행된다.

도커는 이미지를 생성할 수 있다.




| 명령어 | 설명 |
| :--- | :--- |
| `docker images` | 설치된 이미지 목록(용량, ID 등) 확인 |
| `docker rmi [이미지ID]` | 이미지 파일 삭제 (디스크에서 제거) |
| `docker build -t [이름] .` | 현재 폴더의 설정(Dockerfile)으로 이미지 생성 |
| `docker run [옵션] [이미지]` | 이미지를 기반으로 새 컨테이너 실행 |
| `docker ps -a` | 현재 실행 중 및 종료된 모든 컨테이너 목록 조회 |
| `docker stop [ID]` | 실행 중인 컨테이너 작동 중지 |
| `docker start [ID]` | 중지했던 컨테이너 다시 시작 |
| `docker rm [ID]` | 중지된 컨테이너 기록 완전 삭제 |
